# BiraChan-python-discord-bot
Basic Script to learn the Python and Discord Bot basics - Made for friends

The Bot only uses basic prefix and no prefix commands to reply funny messages or call a random picture from turkbira or turksigara.
Currently only available in Turkish. No plans to extend the bot since it is just a small project for close friends.
Bira Chan Bot is a non profit simple python Discord bot.

-----

Python ve Discord Bot temellerini öğrenmek için hazırlanmış basit bir script – Arkadaşlar için yapılmıştır.

Bot, komik mesajlara yanıt vermek veya turkbira ya da turksigara üzerinden rastgele bir fotoğraf çağırmak için yalnızca temel prefix ve prefix'siz komutları kullanır. Şu anda sadece Türkçe olarak kullanılabilir. Bot yalnızca yakın arkadaşlar için yapılmış küçük bir proje olduğu için geliştirme veya kapsamını genişletme gibi bir plan bulunmamaktadır.

Bira Chan Bot, kâr amacı gütmeyen, basit bir Python Discord botudur.
